# 140 — Settings scene, onboarding, menus, placeholder icon (010 · Phase 2)

Shell-UX tier of [010-production-ship](../.docs/feature-todo/010-production-ship.md)
(group 4) per [033-production-ship-plan](../.docs/033-production-ship-plan.md). The
**distribution track (signing / notarization / Sparkle / Web Store / real icon art) is
deliberately out of scope** (owner's call) — this covers only the in-app shell.

## Summary

- **Settings scene (⌘,)** — the standard macOS Settings window (`Settings { }`), giving
  a home to controls that had none:
  - **Browser Capture**: endpoint address, the pairing token (copyable), and
    **Regenerate Token** (stops the endpoint, persists a fresh secret, restarts bound to
    it — the old token dies immediately; re-pair the extension).
  - **Library**: on-disk location + **Show in Finder**.
  - **Setup**: replay the first-run guide.
- **First-run onboarding sheet** — a 4-step walkthrough (install extension → pair token
  → capture → done) shown once, gated on `@AppStorage("AtelierDidCompleteOnboarding")`,
  replayable from Settings. Makes the previously-undiscoverable pairing flow explicit.
- **Menus**: **View ▸ Sort By** (Manual / Newest / Most Viewed, 007) acting on the
  current collection via the focused model, with a checkmark on the active mode. (Edit ▸
  Undo/Redo landed in Phase 1 · changelog 139.)
- **Placeholder app icon** — a generated gradient-tile + "A" monogram across all 10 mac
  slots (16–512 @1x/2x), replacing the empty `AppIcon.appiconset`. A **stand-in for real
  brand art**, not final.

## Architecture note

The shared `IngestionModel` was **lifted from `ContentView` to the App scene** so the
main window and the Settings window drive the same Library instance. `ContentView` now
takes it as an injected `@ObservedObject`; `nav` / `gridPrefs` / `toasts` stay window-local.

## Not in scope (owner owns distribution)

Developer ID signing, notarization, Sparkle auto-update, Web Store listing/packaging,
extension icons, and real icon art are untouched — to be handled by the owner when
shipping externally.
